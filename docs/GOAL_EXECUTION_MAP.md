# Agent Architecture Principles

AI agents should only be introduced when they have:

- Clear responsibility
- Defined inputs
- Required tool access
- Concrete outputs
- Success measurement

Avoid:

- Simulated agent conversations
- Artificial progress reporting
- Agents without real execution capability
