# Loop Engineering Skill

This skill enforces continuous component optimization.

## 8-Step Loop Process

1. **Target Outcome Definition:** Formulate the measurable target outcome.
2. **Build Baseline:** Construct the best reasonable initial version.
3. **Verification:** Test baseline performance against acceptance criteria.
4. **Identify Bottleneck:** Locate the single highest-impact weakness.
5. **Targeted Enhancement:** Implement a fix focused specifically on that weakness.
6. **Re-measurement:** Test again to quantify improvement.
7. **Record Progression:** Document results and decision in `.life-os/changelog/history.json`.
8. **Diminishing Return Stopping:** Stop iterating when marginal gains no longer justify complexity, time, or risk.
